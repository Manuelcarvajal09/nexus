# macOS handoff

Instructions for the session that will review and update the macOS build **on a Mac** (for example Claude Code opened in the Mac's copy of the original project). Everything else in this repository is up to date as of version 0.4.0.

## Where things are

- **This repository** (`main`): the Windows build (Python 3.11 + PySide6/Qt 6), the most complete version of Nexus. Read `README.md`, `UX_AUDIT_2026-11.md` and `ROADMAP_1.0.md` first.
- **Linux build**: branch `linux/auditoria-2026-11`.
- **macOS original**: Swift + SwiftUI/AppKit + Core Data, in `~/Documents/Nexus` on the Mac (called *Nexus-original* in `MIGRATION_LINUX.md`). It is **not** in this repository yet.

## Goals

1. Put the macOS source under version control in this repository, in `macos/` (no build products, no `DerivedData`, no personal data, no signing identities).
2. Bring the macOS app to parity with the Windows build (list below).
3. Prepare a distributable: signed, notarized `.pkg` that lets the user choose **only for me** or **all users** (see `docs/PLATFORMS.md`).
4. Decide, with Manuel, between keeping the native Swift app or moving macOS onto the shared Qt codebase (see "Unification" in `ROADMAP_1.0.md`).

## Parity checklist (what the Windows build does that macOS should match)

Reliability
- [ ] Paste back into the previous app: remember the frontmost app when the panel opens, reactivate it, send ⌘V; if that cannot work, say so and leave the content on the clipboard.
- [ ] Sequential paste (Nexus Stack): copy A, B, C, then ⌘V pastes them in order or reversed; an empty Stack must not swallow ⌘V.
- [ ] Never treat a stale modifier as held (event taps can miss key-ups across screen lock).

Privacy
- [ ] Skip pasteboard items marked as concealed/transient: `org.nspasteboard.ConcealedType`, `org.nspasteboard.TransientType`, `org.nspasteboard.AutoGeneratedType` (password managers set these).
- [ ] Link previews: only public addresses, never one-time/secret links (tokens, codes, signatures, credentials, reset/login paths), with a setting to turn them off. The rules are in `src/nexus/core/web_preview.py` (`is_sensitive_url`, `_is_safe_ip`).
- [ ] Deleting a clip removes it from disk (Core Data/SQLite secure delete or vacuum).

Features and UX
- [ ] English and Spanish interface, automatic from the system language with a manual override. Reuse the wording in `src/nexus/core/i18n_en.py`.
- [ ] Search that ignores accents; quick paste 1–9; rename (titles); delete with undo; pinboards with counts.
- [ ] Stack order labels "In order / Reversed" (no FIFO/LIFO in the UI); arrows when cards overflow; readable error text in light mode (contrast ≥ 4.5:1).
- [ ] The five themes (Liquid Glass, Midnight Teal, Tech Neon, Storem, Minimalist): tokens in `src/nexus/ui/design.py`.

Packaging
- [ ] Bundle id, version and build number aligned with `pyproject.toml` (`0.4.0`).
- [ ] Hardened Runtime, `NSAppleEventsUsageDescription`/Accessibility explanation, login item via `SMAppService`.
- [ ] `productbuild` distribution with `<domains enable_currentUserHome="true" enable_localSystem="true"/>`.
- [ ] Signing and notarization need Manuel's Apple Developer account: ask before using any identity; never commit certificates or passwords.

## When done

Open a pull request against `main` that adds `macos/`, updates `docs/PLATFORMS.md` (macOS column) and the README's platform table, and lists what was verified on the Mac and what was not.
